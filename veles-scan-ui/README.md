# Veles Scan — веб-интерфейс

Веб-интерфейс сервиса поиска организаций и сбора контактных данных. Стек: Next.js, React, TypeScript, Tailwind CSS и PostgreSQL.

Пользователь создаёт проект, описывает нужную выборку обычным текстом, проверяет распознанные условия и стоимость, запускает обработку и скачивает готовый Excel. Интерфейс подключён к FastAPI backend через `BACKEND_API_URL`: используются предварительный просмотр запроса, оценка цены, запуск задания, получение статусов и результата, а также отмена обработки.

## Запуск (унифицированный стек)

Запускайте полный стек из корня репозитория по инструкции в [основном README](../README.md). До запуска создайте `.env` и `veles-scan-back/checko_runtime_config.py` из примеров и настройте ключ OpenAI и параметры сборщика.

```bash
cd ..
./start.sh
```

Откройте `http://localhost:3000`.

Для загрузки тестовых данных в локальную базу интерфейса:

```bash
cd veles-scan-ui
./scripts/load-test-data.sh
```

## Реализованные страницы

- `/` и `/login` — вход в личный кабинет.
- `/register` и `/forgot-password` — регистрация и форма восстановления доступа.
- `/projects` — список проектов.
- `/projects/new` — создание проекта.
- `/projects/[id]` — условия поиска, запуск, прогресс и результат проекта.
- `/finance` — баланс, операции и пополнение.
- `/settings` — настройки пользователя.
- `/support` — обращения в поддержку.
- `/admin` и `/admin/projects/[id]` — административный интерфейс и подробности обработки проектов.

## Интеграция с backend

В контейнерном стеке `BACKEND_API_URL` задаётся как `http://api:8080`. При отдельном запуске интерфейса укажите адрес доступного backend и параметры подключения к PostgreSQL.

Задания выполняются фоновыми воркерами backend. Интерфейс сохраняет связь проекта с заданием, обновляет его состояние и получает файл результата из хранилища через API.

## Пополнение баланса через Т-Банк

Для включения оплаты на вкладке `/finance` задайте переменные окружения в корневом `.env`; Compose передаёт их сервису `scan_ui`:

- `TBANK_TERMINAL_KEY`
- `TBANK_PASSWORD`
- `TBANK_NOTIFICATION_URL` (опционально; по умолчанию собирается как `APP_PUBLIC_URL + /api/payments/tbank/notification`).

Задайте `APP_PUBLIC_URL` для внешнего адреса приложения, чтобы сформировать корректные адреса возврата и уведомлений.

После настройки пользователь может инициировать платёж, а виджет Т-Банка открывается в iframe в модалке пополнения.
